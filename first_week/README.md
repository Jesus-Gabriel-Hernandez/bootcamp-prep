# Semana 1 - Ejercicios de preparación

Esta carpeta contiene los notebooks de los **7 días de preparación** previos al bootcamp de Ironhack.

## Día 7 - Repaso
En este notebook se pone en práctica todo lo aprendido durante la semana:

- Creación de un dataset sencillo con productos, ventas, precios y categorías.
- Exploración con `info()`, `head()` y `describe()`.
- Estadística descriptiva: media, mediana, desviación estándar.
- Visualización con histogramas, boxplots y gráficos de violín.
- Conclusiones sobre ventas y precios (distribuciones, valores extremos, tendencias).

El ejercicio busca integrar **Python + pandas + estadística + visualización** en un análisis completo.
