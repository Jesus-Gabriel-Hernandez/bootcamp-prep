# Preparación Bootcamp Data Science de Ironhack

Este repositorio contiene los ejercicios de preparación realizados antes del inicio del bootcamp.  
El objetivo es reforzar fundamentos de **Python, análisis de datos, estadística básica y visualización** en un periodo de 7 días.

## Estructura
- `first_week/`: contiene los notebooks del día 1 al día 7.
    - Cada notebook aborda un tema distinto de preparación.
    - El día 7 es un ejercicio de **repaso general**.

## Tecnologías usadas
- Python 3
- pandas
- matplotlib
- seaborn

---
Este repositorio se cierra al finalizar el día 7.  
Durante el bootcamp se usará un nuevo repositorio específico para los proyectos principales.
